# Comment.io for Codex

Comment.io collaboration for local macOS and Linux sessions. The plugin includes setup, comment, new-comm, and listen. It uses system POSIX sh, curl, OpenSSL, and direct HTTPS APIs; no additional language runtime or package installation is required on the supported hosts. The runtime checks for curl and OpenSSL before setup so a missing system dependency fails clearly. Private runtime helpers keep stored credentials and secret text outside model-visible output.
